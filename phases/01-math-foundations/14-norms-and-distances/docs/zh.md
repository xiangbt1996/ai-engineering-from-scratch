# 范数与距离

> 你的距离函数决定了"相似"的含义。选错了，后面一切都会崩。

**类型：** 动手构建
**语言：** Python
**前置课程：** 第一阶段，第 01 课（线性代数直觉）、第 02 课（向量、矩阵与运算）
**时间：** 约 90 分钟

## 学习目标

- 从零实现 L1、L2、余弦、马氏距离、Jaccard 和编辑距离函数
- 为给定的 ML 任务选择合适的距离度量，并解释为什么其他选择不合适
- 将 L1 和 L2 范数与 LASSO 和 Ridge 正则化及其几何约束区域联系起来
- 演示同一数据集在不同度量下如何产生不同的最近邻

## 问题背景

你有两个向量。也许是词嵌入（Word Embedding），也许是用户画像，也许是像素数组。你需要知道：它们有多接近？

答案完全取决于你选择哪个距离函数。同样两个数据点，在一种度量下可能是最近邻，在另一种度量下却相距甚远。你的 KNN 分类器、推荐引擎、向量数据库、聚类算法、损失函数——它们都依赖于这个选择。选错了，你的模型就在优化错误的目标。

没有普遍最优的距离。L2 适用于空间数据。余弦相似度在 NLP 中占主导地位。Jaccard 处理集合。编辑距离处理字符串。马氏距离考虑相关性。Wasserstein 移动概率质量。每一种都编码了对"相似"的不同假设。

本课从零构建每一种主要的距离函数，告诉你每种函数何时是正确的工具，并演示同样的数据如何因为使用不同的度量而产生完全不同的最近邻。

## 核心概念

### 范数：度量向量的大小

范数（Norm）度量向量的"大小"。两个向量之间的每种距离函数都可以写成它们差的范数：d(a, b) = ||a - b||。因此，理解范数就是理解距离。

### L1 范数（曼哈顿距离）

L1 范数是所有分量绝对值的总和。

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

它被称为曼哈顿距离（Manhattan Distance），因为它度量的是在只能沿坐标轴移动的城市网格上需要走多远，不能走对角线。

```
点 A = (1, 1)
点 B = (4, 5)

L1 距离 = |4-1| + |5-1| = 3 + 4 = 7

在网格上，你向东走 3 个街区，向北走 4 个街区。
```

何时使用 L1：
- 高维稀疏数据（文本特征、独热编码）
- 需要对异常值具有鲁棒性时（单个巨大差异不会主导结果）
- 特征选择问题（L1 正则化促进稀疏性）

与 L1 正则化（Lasso）的联系：在损失函数中加入 ||w||_1 会惩罚权重绝对值之和。这会将小权重推到恰好为零，实现自动特征选择。L1 惩罚在权重空间中创建菱形约束区域，菱形的顶角落在坐标轴上——正是某些权重为零的位置。

与损失函数的联系：平均绝对误差（MAE）是预测值与目标值之间 L1 距离的平均值。它对所有误差施加线性惩罚，因此比 MSE 对异常值更鲁棒。

### L2 范数（欧氏距离）

L2 范数是直线距离，等于分量平方和的平方根。

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

这就是你在几何课上学过的距离。n 维空间中的勾股定理。

```
点 A = (1, 1)
点 B = (4, 5)

L2 距离 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

穿过网格的直线。
```

何时使用 L2：
- 低到中等维度的连续数据
- 特征尺度可比较时
- 物理距离（空间数据、传感器读数）
- 像素级别的图像相似度

与 L2 正则化（Ridge）的联系：在损失函数中加入 ||w||_2^2 会惩罚大权重。与 L1 不同，它不会将权重推到零，而是按比例将所有权重向零收缩。L2 惩罚创建圆形约束区域，没有坐标轴上的角点。权重会变小，但很少恰好为零。

与损失函数的联系：均方误差（MSE）是 L2 距离平方的平均值。平方运算使得大误差受到的惩罚远大于小误差。

```
MAE (L1 损失):  |y - y_hat|         线性惩罚。对异常值鲁棒。
MSE (L2 损失):  (y - y_hat)^2       二次惩罚。对异常值敏感。
```

### Lp 范数：通用范数族

L1 和 L2 是 Lp 范数的特例：

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

不同的 p 值产生不同形状的"单位球"（与原点距离为 1 的所有点的集合）：

```
p=1:    菱形            （顶角在坐标轴上）
p=2:    圆/球            （常见的圆球）
p=3:    超椭圆           （圆角方形）
p=inf:  方形/超立方体    （沿坐标轴的平面）
```

### L-infinity 范数（切比雪夫距离）

当 p 趋向无穷时，Lp 范数收敛为分量绝对值的最大值。

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

两点之间的距离由差异最大的那个单一维度决定，其他维度全部被忽略。

```
点 A = (1, 1)
点 B = (4, 5)

L-inf 距离 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

何时使用 L-infinity：
- 当任意单个维度的最坏偏差最重要时
- 棋盘（国际象棋中的王按 L-infinity 移动：任意方向一步的代价都是 1）
- 制造公差（每个维度都必须在规格范围内）

### 余弦相似度与余弦距离

余弦相似度（Cosine Similarity）度量两个向量之间的角度，忽略它们的大小。

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

取值范围从 -1（方向相反）到 +1（方向相同）。垂直的向量余弦相似度为 0。

余弦距离将其转换为距离：cosine_distance = 1 - cosine_similarity。取值范围从 0（方向完全相同）到 2（方向完全相反）。

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

为什么余弦相似度在 NLP 和嵌入中占主导地位：在文本中，文档长度不应影响相似度。一篇关于猫的文档如果是另一篇关于猫的文档的两倍长，它们仍然应该是"相似的"。余弦相似度忽略大小（长度），只关心方向。两篇词频分布相同但长度不同的文档指向相同的方向，余弦相似度为 1.0。

何时使用余弦相似度：
- 文本相似度（TF-IDF 向量、词嵌入、句子嵌入）
- 任何大小是噪声、方向是信号的领域
- 推荐系统（用户偏好向量）
- 嵌入搜索（向量数据库几乎总是使用余弦或点积）

### 点积相似度 vs 余弦相似度

两个向量的点积（Dot Product）是：

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(夹角)
```

余弦相似度是点积除以两个向量的模长。当两个向量都已经做了单位归一化（模长 = 1）时，点积和余弦相似度完全一致。

```
如果 ||a|| = 1 且 ||b|| = 1：
    a . b = cos(a 和 b 之间的夹角)
```

两者的区别：点积包含了大小信息。模长更大的向量会获得更高的点积分数。这在某些检索系统中很重要——你希望"热门"的项目排名更高。模长充当了隐含的质量或重要性信号。

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

两者在方向上一致，但点积还反映了大小。
```

实践中：
- 当你需要纯方向相似度时，使用余弦相似度
- 当大小携带有意义的信息时，使用点积
- 许多向量数据库（Pinecone、Weaviate、Qdrant）允许你在两者之间选择
- 如果你的嵌入已经做了 L2 归一化，选哪个都一样

### 马氏距离

欧氏距离对所有维度一视同仁。但如果你的特征之间存在相关性或尺度不同，L2 会给出误导性的结果。

马氏距离（Mahalanobis Distance）考虑了数据的协方差结构。

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

其中 S 是数据的协方差矩阵。

直觉上：马氏距离首先对数据进行去相关和归一化（白化），然后在变换后的空间中计算 L2 距离。如果 S 是单位矩阵（不相关、单位方差的特征），马氏距离就退化为欧氏距离。

```
例子：身高和体重是相关的。
身高 6'2"、体重 180 磅并不罕见。
身高 5'0"、体重 180 磅就不寻常了。

欧氏距离可能认为两者与均值的距离相同。
马氏距离能正确识别第二个为异常点，
因为它考虑了身高和体重之间的相关性。
```

何时使用马氏距离：
- 异常值检测（与均值马氏距离大的点是异常值）
- 特征尺度和相关性不同时的分类
- 当你有足够的数据来估计可靠的协方差矩阵时
- 制造业质量控制（多变量过程监控）

### Jaccard 相似度（用于集合）

Jaccard 相似度度量两个集合的重叠程度。

```
J(A, B) = |A 交 B| / |A 并 B|
```

取值范围从 0（无重叠）到 1（完全相同）。Jaccard 距离 = 1 - Jaccard 相似度。

```
A = {cat, dog, fish}
B = {cat, bird, fish, snake}

交集 = {cat, fish}            大小 = 2
并集 = {cat, dog, fish, bird, snake}  大小 = 5

Jaccard 相似度 = 2/5 = 0.4
Jaccard 距离 = 0.6
```

何时使用 Jaccard：
- 比较标签、类别或特征的集合
- 基于词汇出现（而非频率）的文档相似度
- 近似重复检测（Jaccard 的 MinHash 近似）
- 比较二值特征向量（有/无数据）
- 评估分割模型（IoU = Jaccard）

### 编辑距离（Levenshtein 距离）

编辑距离计算将一个字符串变换为另一个字符串所需的最少单字符操作次数。操作包括：插入、删除或替换。

```
"kitten" -> "sitting"

kitten -> sitten  （将 k 替换为 s）
sitten -> sittin  （将 e 替换为 i）
sittin -> sitting （插入 g）

编辑距离 = 3
```

使用动态规划计算。填充一个矩阵，其中第 (i, j) 项是字符串 A 的前 i 个字符与字符串 B 的前 j 个字符之间的编辑距离。

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

何时使用编辑距离：
- 拼写检查和纠正
- DNA 序列比对（使用加权操作）
- 模糊字符串匹配
- 混乱文本数据的去重

### KL 散度（不是距离，但常被当作距离使用）

KL 散度（KL Divergence）度量一个概率分布与另一个概率分布的差异。在第 09 课中已经介绍过，但它属于本课的讨论范围，因为人们经常将它当作"距离"使用，尽管它并不是。

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

关键性质：KL 散度不是对称的。

```
D_KL(P || Q) != D_KL(Q || P)
```

这意味着它不满足距离度量的基本要求。它也不满足三角不等式。它是散度，不是距离。

前向 KL（D_KL(P || Q)）是"均值追踪型"（Mean-Seeking）：Q 试图覆盖 P 的所有模式。
反向 KL（D_KL(Q || P)）是"模式追踪型"（Mode-Seeking）：Q 集中在 P 的单个模式上。

KL 散度出现的场景：
- VAE（ELBO 中的 KL 项将隐变量分布推向先验）
- 知识蒸馏（学生模型试图匹配教师模型的分布）
- RLHF（KL 惩罚使微调模型保持接近基础模型）
- 策略梯度方法（约束策略更新）

### Wasserstein 距离（推土机距离）

Wasserstein 距离度量将一个概率分布变换为另一个所需的最小"功"。可以这样想：如果一个分布是一堆土，另一个是一个坑，你需要搬运多少土、搬多远？

```
W(P, Q) = inf 在所有运输方案 gamma 上 E[d(x, y)]
```

对于一维分布，它简化为累积分布函数绝对差的积分：

```
W_1(P, Q) = integral |CDF_P(x) - CDF_Q(x)| dx
```

为什么 Wasserstein 距离重要：
- 它是真正的度量（对称，满足三角不等式）
- 即使分布没有重叠，它也能提供梯度（而 KL 散度会趋向无穷）
- 这一性质使它成为 Wasserstein GAN（WGAN）的核心，解决了原始 GAN 的训练不稳定问题

```
没有重叠的分布：

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL 散度：无穷（对零取对数）
Wasserstein：4（将所有质量移动 4 个位置）

Wasserstein 给出有意义的梯度。KL 不能。
```

何时使用 Wasserstein 距离：
- GAN 训练（WGAN、WGAN-GP）
- 比较可能没有重叠的分布
- 最优传输问题
- 图像检索（比较颜色直方图）

### 为什么不同任务需要不同的距离

| 任务 | 最佳距离 | 原因 |
|------|---------|------|
| 文本相似度 | 余弦 | 大小是噪声，方向是语义 |
| 图像像素比较 | L2 | 空间关系重要，特征尺度可比 |
| 高维稀疏特征 | L1 | 鲁棒，不会放大罕见的大差异 |
| 集合重叠（标签、类别） | Jaccard | 数据天然是集合形式，不是向量 |
| 字符串匹配 | 编辑距离 | 操作符合人类编辑直觉 |
| 异常值检测 | 马氏距离 | 考虑特征相关性和尺度 |
| 比较分布 | KL 散度 | 度量使用 Q 代替 P 时损失的信息 |
| GAN 训练 | Wasserstein | 即使分布不重叠也能提供梯度 |
| 嵌入（向量数据库） | 余弦或点积 | 嵌入被训练为用方向编码语义 |
| 推荐 | 点积 | 大小可以编码热度或置信度 |
| DNA 序列 | 加权编辑距离 | 不同核苷酸对的替换代价不同 |
| 制造业质量控制 | L-infinity | 任意维度的最坏偏差最重要 |

### 与损失函数的联系

损失函数就是应用于预测值与目标值之间的距离函数。

```
损失函数          使用的距离          行为
MSE              L2 平方           重罚大误差
MAE              L1                等量惩罚所有误差
Huber 损失       大误差用 L1，      两者兼顾：对异常值鲁棒，
                 小误差用 L2       零点附近梯度光滑
交叉熵           KL 散度            度量分布不匹配
合页损失         max(0, margin - d) 只惩罚低于间隔的部分
三元组损失        L2（通常）         拉近正样本，推远负样本
对比损失         L2                相似对拉近，不相似对
                                   推到间隔之外
```

### 与正则化的联系

正则化在损失函数中加入权重的范数惩罚。

```
L1 正则化（Lasso）：  loss + lambda * ||w||_1
  -> 稀疏权重。某些权重恰好变为零。
  -> 自动特征选择。
  -> 解在零点处有角点（不可微）。

L2 正则化（Ridge）：  loss + lambda * ||w||_2^2
  -> 权重变小。所有权重向零收缩。
  -> 不做特征选择（没有权重恰好变为零）。
  -> 处处光滑。

弹性网络（Elastic Net）：loss + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> 结合 L1 的稀疏性和 L2 的稳定性。
  -> 相关特征组会被一起保留或一起丢弃。
```

为什么 L1 产生稀疏性而 L2 不会：在二维权重空间中想象约束区域。L1 是菱形，L2 是圆形。损失函数的等高线（椭圆）最可能在菱形的角点处相切，而角点处某个权重为零。它们在圆形的光滑点处相切，此时两个权重都不为零。

### 最近邻搜索

每种距离函数都隐含着一个最近邻搜索（Nearest Neighbor Search）问题：给定一个查询点，在数据集中找到最近的点。

精确最近邻搜索在 n 个 d 维数据点的数据集上，每次查询的复杂度为 O(n * d)。对于大数据集来说，这太慢了。

近似最近邻（Approximate Nearest Neighbor, ANN）算法用少量精度换取巨大的速度提升：

```
算法            方法                         应用
KD 树           轴对齐空间划分               scikit-learn（低维）
Ball 树         嵌套超球体                   scikit-learn（中维）
LSH             随机哈希投影                 近似重复检测
HNSW            分层可导航小世界图            FAISS、Qdrant、Weaviate
IVF             基于聚类的倒排文件索引        FAISS（十亿级规模）
乘积量化         压缩向量，在压缩空间中搜索   FAISS（内存受限场景）
```

HNSW（Hierarchical Navigable Small World，分层可导航小世界）是现代向量数据库中的主流算法。它构建一个多层图，每个节点连接到其近似最近邻。搜索从顶层开始（稀疏，长跳转），逐层下降到底层（密集，短跳转）。

## 实际应用

最常见的实际用途：在向量数据库中查找相似项目。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"Top 5 most similar to item 0: {top_k}")
print(f"Similarities: {similarities[top_k]}")
```

当你调用 `model.encode(text)` 然后搜索向量数据库时，底层就是这样工作的。嵌入模型将文本映射为向量。向量数据库计算你的查询向量与每个存储向量之间的余弦相似度（或点积），使用 ANN 算法来避免检查所有向量。

## 练习

1. 计算 (1, 2, 3) 和 (4, 0, 6) 之间的 L1、L2 和 L-infinity 距离。验证 L-inf <= L2 <= L1 对任意一对点总是成立。证明为什么这个顺序是有保证的。

2. 创建两个向量，使得余弦相似度很高（> 0.9）但 L2 距离很大（> 10）。从几何角度解释发生了什么。然后创建两个向量，使得余弦相似度很低（< 0.3）但 L2 距离很小（< 0.5）。

3. 实现一个函数，接收一个数据集和一个查询点，返回在 L1、L2、余弦和马氏距离下的最近邻。找到一个数据集，使得四种度量对最近邻的判断都不同。

4. 手动使用 CDF 方法计算 [0.5, 0.5, 0, 0] 和 [0, 0, 0.5, 0.5] 之间的 Wasserstein 距离。然后计算 [0.25, 0.25, 0.25, 0.25] 和 [0, 0, 0.5, 0.5] 之间的 Wasserstein 距离。哪个更大？为什么？

5. 实现 MinHash 来近似 Jaccard 相似度。生成 100 个随机集合，计算所有配对的精确 Jaccard，并与使用 50、100 和 200 个哈希函数的 MinHash 近似进行比较。画出近似误差图。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|---------|---------|
| 范数 | "向量的大小" | 将向量映射为非负标量的函数，需满足三角不等式、绝对齐次性，且仅对零向量为零 |
| L1 范数 | "曼哈顿距离" | 分量绝对值之和。在优化中产生稀疏性。对异常值鲁棒 |
| L2 范数 | "欧氏距离" | 分量平方和的平方根。欧氏空间中的直线距离 |
| Lp 范数 | "广义范数" | 分量绝对值 p 次方之和的 p 次方根。L1 和 L2 是其特例 |
| L-infinity 范数 | "最大范数"或"切比雪夫距离" | 分量绝对值的最大值。是 p 趋向无穷时 Lp 的极限 |
| 余弦相似度 | "向量间的角度" | 点积除以两个向量的模长归一化。范围从 -1 到 +1。忽略向量长度 |
| 余弦距离 | "1 减余弦相似度" | 将余弦相似度转换为距离。范围从 0 到 2 |
| 点积 | "未归一化的余弦" | 逐分量乘积之和。等于余弦相似度乘以两个向量的模长 |
| 马氏距离 | "考虑相关性的距离" | 在使用数据协方差矩阵白化（去相关和归一化）后的空间中计算的 L2 距离 |
| Jaccard 相似度 | "集合重叠" | 交集大小除以并集大小。适用于集合，不适用于向量 |
| 编辑距离 | "Levenshtein 距离" | 将一个字符串变换为另一个所需的最少插入、删除和替换次数 |
| KL 散度 | "分布间的距离" | 不是真正的距离（不对称）。度量用 Q 编码 P 时额外需要的比特数 |
| Wasserstein 距离 | "推土机距离" | 将一个分布的质量搬运到另一个分布的最小功。是真正的度量 |
| 近似最近邻 | "ANN 搜索" | 以比精确搜索快得多的速度找到近似最近点的算法（HNSW、LSH、IVF） |
| HNSW | "向量数据库算法" | 分层可导航小世界图。用于快速近似最近邻搜索的多层图结构 |
| L1 正则化 | "Lasso" | 在损失函数中加入权重的 L1 范数。将权重驱动到零（稀疏性） |
| L2 正则化 | "Ridge"或"权重衰减" | 在损失函数中加入权重的 L2 范数平方。将权重向零收缩但不产生稀疏性 |
| 弹性网络 | "L1 + L2" | 结合 L1 和 L2 正则化。比单独使用任一方法更好地处理相关特征组 |
