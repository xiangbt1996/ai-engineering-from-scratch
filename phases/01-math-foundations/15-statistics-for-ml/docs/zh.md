# 机器学习中的统计学

> 统计学让你知道模型到底是真有效，还是只是运气好。

**类型：** 动手构建
**语言：** Python
**前置课程：** 第一阶段，第 06 课（概率与分布）、第 07 课（贝叶斯定理）
**时长：** 约 120 分钟

## 学习目标

- 从零实现描述性统计、Pearson/Spearman 相关系数和协方差矩阵的计算
- 执行假设检验（t 检验、卡方检验），正确解读 p 值和置信区间
- 使用自助法（Bootstrap）重采样构建任意指标的置信区间，无需分布假设
- 区分统计显著性与实际显著性，使用效应量进行判断

## 问题引入

你训练了两个模型。模型 A 在测试集上得分 0.87，模型 B 得分 0.89。你部署了模型 B。三周后，线上指标反而变差了。发生了什么？

模型 B 并没有真正优于模型 A。0.02 的差异只是噪声。你的测试集太小，或者方差太大，或者二者兼有。你把随机波动当成了性能提升。

这种情况随处可见。Kaggle 排行榜的排名大洗牌。无法复现的论文。基于几百个样本就宣布赢家的 A/B 测试。根本原因总是一样的：有人跳过了统计分析。

统计学为你提供区分信号与噪声的工具。它告诉你一个差异何时是真实的、你的置信度应该有多高、以及你需要多少数据才能信任一个结果。每一条机器学习流水线、每一次模型比较、每一个实验都需要统计学。没有它，你只是在猜。

## 核心概念

### 描述性统计：概括你的数据

在建模之前，你需要知道数据长什么样。描述性统计（Descriptive Statistics）将数据集压缩成少数几个数字来捕捉其形态。

**集中趋势度量**回答"中间在哪里？"

```
均值（Mean）：所有值的总和 / 个数
        mu = (1/n) * sum(x_i)

中位数（Median）：排序后的中间值
        对异常值具有鲁棒性。如果你有 [1, 2, 3, 4, 1000]，均值是 202
        但中位数是 3。

众数（Mode）：出现最频繁的值
        适用于分类数据。对于连续数据，通常没有太大信息量。
```

均值是平衡点，中位数是中间标记。当二者偏离时，分布是偏斜的。收入分布的均值 >> 中位数（受亿万富翁影响的右偏）。训练过程中的损失分布通常均值 << 中位数（受简单样本影响的左偏）。

**离散度度量**回答"数据有多分散？"

```
方差（Variance）：与均值偏差的平方的平均值
            sigma^2 = (1/n) * sum((x_i - mu)^2)

标准差（Standard Deviation）：方差的平方根
                     sigma = sqrt(sigma^2)
                     与数据同单位，因此更易解释。

极差（Range）：max - min
            对异常值敏感。几乎从不单独使用。

四分位距（IQR）：Q3 - Q1（Interquartile Range）
            数据中间 50% 的范围。
            对异常值鲁棒。用于箱线图和异常值检测。
```

**百分位数（Percentile）**将排序后的数据分成 100 等份。第 25 百分位（Q1）意味着 25% 的值低于此点。第 50 百分位就是中位数。第 75 百分位就是 Q3。

```
用于延迟监控：
  P50 = 中位数延迟       （典型用户体验）
  P95 = 第 95 百分位     （较差但非最坏情况）
  P99 = 第 99 百分位     （尾部延迟，通常是中位数的 10 倍）
```

在机器学习中，你关注百分位数的场景包括推理延迟、预测置信度分布和误差分布分析。一个平均误差很低但 P99 误差很高的模型，对于安全关键应用可能毫无用处。

**样本统计量 vs 总体统计量。** 从样本计算方差时，除以 (n-1) 而不是 n。这就是贝塞尔校正（Bessel's Correction）。它补偿了样本均值不是真实总体均值这一事实。用 n 做分母时，你会系统性地低估真实方差。用 (n-1) 时，估计是无偏的。

```
总体方差：sigma^2 = (1/N) * sum((x_i - mu)^2)
样本方差：s^2     = (1/(n-1)) * sum((x_i - x_bar)^2)
```

实际使用中：如果 n 很大（几千个样本），差异可以忽略不计。如果 n 很小（几十个样本），就很重要了。

### 相关性：变量如何协同变化

相关性衡量两个变量之间线性关系的强度和方向。

**Pearson 相关系数**衡量线性关联：

```
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1: 完美正线性关系
r = -1: 完美负线性关系
r =  0: 无线性关系（但可能存在非线性关系！）

范围：[-1, 1]
```

Pearson 假设关系是线性的，且两个变量大致服从正态分布。它对异常值敏感。一个极端点就能把 r 从 0.1 拉到 0.9。

**Spearman 秩相关系数**衡量单调关联：

```
1. 将每个值替换为其秩（1, 2, 3, ...）
2. 对秩计算 Pearson 相关系数

Spearman 能捕捉任何单调关系，不仅限于线性关系。
如果 y = x^3，Pearson 的 r < 1，但 Spearman 的 rho = 1。
```

**何时使用哪个：**

```
Pearson：  两个变量都是连续的且大致正态分布。
           你特别关注线性关系。
           没有极端异常值。

Spearman：有序数据（排名、评分）。
           数据不是正态分布的。
           你怀疑存在单调但非线性的关系。
           存在异常值。
```

**黄金法则：** 相关不意味着因果。冰淇淋销量和溺水人数相关，因为两者都在夏天增加。模型准确率和参数数量相关，但增加参数并不会自动提高准确率（参见：过拟合）。

### 协方差矩阵

两个变量之间的协方差（Covariance）衡量它们如何一起变化：

```
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0: X 和 Y 倾向于同时增大
Cov(X, Y) < 0: 当 X 增大时，Y 倾向于减小
Cov(X, Y) = 0: 无线性共变关系
```

对于 d 个特征，协方差矩阵 C 是一个 d x d 的矩阵，其中 C[i][j] = Cov(feature_i, feature_j)。对角线元素 C[i][i] 是每个特征的方差。

```
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

性质：
  - 对称的：C[i][j] = C[j][i]
  - 半正定的：所有特征值 >= 0
  - 对角线 = 方差
  - 非对角线 = 协方差
```

**与 PCA 的联系。** PCA 对协方差矩阵进行特征分解。特征向量是主成分（最大方差方向）。特征值表示每个成分捕获了多少方差。这正是第 10 课所涵盖的内容，但现在你理解了为什么协方差矩阵是正确的分解对象：它编码了数据中所有成对的线性关系。

**与相关性的联系。** 相关矩阵是标准化变量（每个变量除以其标准差）的协方差矩阵。相关性对协方差进行归一化，使所有值落在 [-1, 1] 范围内。

### 假设检验

假设检验（Hypothesis Testing）是在不确定性下做出决策的框架。你从一个主张出发，收集数据，然后判断数据是否与该主张一致。

**基本设定：**

```
零假设（H0）：       默认假设，通常是"无效果"
备择假设（H1）：     你试图证明的东西

示例：
  H0：模型 A 和模型 B 的准确率相同
  H1：模型 B 的准确率高于模型 A
```

**p 值**是在假设 H0 为真的情况下，观察到与已有数据一样极端或更极端的数据的概率。它不是 H0 为真的概率。这是统计学中最常见的误解。

```
p 值 = P(数据如此极端 | H0 为真)

如果 p 值 < alpha（通常为 0.05）：
    拒绝 H0。结果"具有统计显著性"。
如果 p 值 >= alpha：
    无法拒绝 H0。你没有足够的证据。
    这不意味着 H0 是正确的。
```

**置信区间（Confidence Interval）**给出参数的合理取值范围：

```
均值的 95% 置信区间：
    x_bar +/- z * (s / sqrt(n))

其中 z = 1.96（对应 95% 置信水平）

解读：如果你多次重复这个实验，95% 的计算区间会包含真实均值。
这不意味着真实均值有 95% 的概率落在这个特定区间内。
```

置信区间的宽度反映精确度。宽区间意味着高不确定性。窄区间意味着估计精确（但如果数据有偏差，不一定准确）。

### t 检验

t 检验（t-test）比较均值。它有多种变体。

**单样本 t 检验：**总体均值是否不同于假设值？

```
t = (x_bar - mu_0) / (s / sqrt(n))

自由度 = n - 1
```

**双样本 t 检验（独立样本）：**两组均值是否不同？

```
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

这是 Welch t 检验，不假设方差相等。
除非有特定理由假设方差相等，否则始终使用 Welch 检验。
```

**配对 t 检验：**当测量成对出现时（同一模型在相同数据划分上评估）：

```
计算每对的差值 d_i = x_i - y_i
然后对 d_i 值进行 mu_0 = 0 的单样本 t 检验
```

在机器学习中，配对 t 检验很常见：你在相同的 10 折交叉验证上运行两个模型，然后逐对比较它们的分数。

### 卡方检验

卡方检验（Chi-squared Test）检查观察频率是否与期望频率匹配。适用于分类数据。

```
chi^2 = sum((观察值 - 期望值)^2 / 期望值)

示例：语言模型的输出分布是否与训练分布在各类别上匹配？

类别        观察值    期望值
正面          120       100
负面           80       100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

在 1 个自由度下，chi^2 = 8 对应 p < 0.005。
差异是显著的。
```

### 机器学习模型的 A/B 测试

机器学习中的 A/B 测试与网页 A/B 测试不同。模型比较有其特殊挑战：

```
1. 相同测试集：两个模型必须在完全相同的数据上评估。
               不同的测试集使比较毫无意义。

2. 多个指标：  仅有准确率是不够的。你需要精确率、
               召回率、F1、延迟和公平性指标。

3. 方差：      使用交叉验证或自助法来估计每个指标的方差，
               而不仅仅是点估计。

4. 数据泄漏：  如果测试集在模型选择过程中被使用过，
               你的比较就有偏差。留出一个最终测试集。
```

**操作步骤：**

```
1. 定义你的指标和显著性水平（alpha = 0.05）
2. 在相同的 k 折交叉验证划分上运行两个模型
3. 收集配对分数：[(a1, b1), (a2, b2), ..., (ak, bk)]
4. 计算差值：d_i = b_i - a_i
5. 对差值进行配对 t 检验
6. 检查：平均差值是否显著异于 0？
7. 计算平均差值的置信区间
8. 计算效应量（Cohen's d）来判断实际显著性
```

### 统计显著性 vs 实际显著性

一个结果可以是统计显著的，但在实际中毫无意义。当数据量足够大时，即使微不足道的差异也会变得统计显著。

```
示例：
  模型 A 准确率：0.9234
  模型 B 准确率：0.9237
  n = 1,000,000 测试样本
  p 值 = 0.001

统计显著？是的。
实际显著？0.03% 的提升不值得部署新模型的工程成本。
```

**效应量（Effect Size）**量化差异有多大，与样本量无关：

```
Cohen's d = (mean_1 - mean_2) / pooled_std

d = 0.2: 小效应
d = 0.5: 中等效应
d = 0.8: 大效应
```

始终同时报告 p 值和效应量。p 值告诉你差异是否真实，效应量告诉你差异是否重要。

### 多重比较问题

当你检验多个假设时，其中一些会因为偶然而"显著"。如果你在 alpha = 0.05 下检验 20 个假设，即使什么都没发生，你也预期会有 1 个假阳性。

```
P(至少一个假阳性) = 1 - (1 - alpha)^m

m = 20 次检验，alpha = 0.05：
P(假阳性) = 1 - 0.95^20 = 0.64

你有 64% 的概率出现至少一个假阳性。
```

**Bonferroni 校正：** 将 alpha 除以检验次数。

```
调整后的 alpha = alpha / m = 0.05 / 20 = 0.0025

仅当 p 值 < 0.0025 时才拒绝 H0。
保守但简单。在检验独立时有效。
```

在机器学习中，当你跨多个指标比较模型、测试多种超参数配置或在多个数据集上评估时，这个问题就很重要。

### 自助法

自助法（Bootstrap）通过有放回地重采样数据来估计统计量的抽样分布，不需要对底层分布做任何假设。

**算法：**

```
1. 你有 n 个数据点
2. 有放回地抽取 n 个样本（某些点出现多次，某些根本不出现）
3. 在这个自助样本上计算你的统计量
4. 重复 B 次（通常 B = 1000 到 10000）
5. 自助统计量的分布近似于抽样分布
```

**自助法置信区间（百分位法）：**

```
对 B 个自助统计量排序
95% CI = [第 2.5 百分位, 第 97.5 百分位]
```

**自助法对机器学习的重要性：**

```
- 测试集准确率是一个点估计。自助法给你置信区间。
- 你不能假设指标分布是正态的（特别是 AUC、F1、
  precision at k）。
- 自助法对任何统计量都有效：中位数、两个均值的比值、
  两个模型之间 AUC 的差异。
- 不需要封闭形式的公式。
```

**自助法用于模型比较：**

```
1. 你有模型 A 和模型 B 在同一测试集上的预测
2. 对于每次自助迭代：
   a. 有放回地重采样测试索引
   b. 在重采样集上计算 metric_A 和 metric_B
   c. 存储 diff = metric_B - metric_A
3. 差值的 95% CI：
   [差值的第 2.5 百分位, 差值的第 97.5 百分位]
4. 如果 CI 不包含 0，差异是显著的
```

这比配对 t 检验更稳健，因为它不做任何分布假设。

### 参数检验 vs 非参数检验

**参数检验（Parametric Tests）**假设数据服从特定分布（通常是正态分布）：

```
t 检验：     假设数据正态分布（或 n 足够大时由中心极限定理保证）
方差分析（ANOVA）：假设正态性和方差齐性
Pearson r：  假设双变量正态性
```

**非参数检验（Non-parametric Tests）**不做分布假设：

```
Mann-Whitney U 检验：比较两组（替代独立 t 检验）
Wilcoxon 符号秩检验：比较配对数据（替代配对 t 检验）
Spearman rho：      基于秩的相关性（替代 Pearson）
Kruskal-Wallis 检验：比较多组（替代方差分析）
```

**何时使用非参数检验：**

```
- 小样本量（n < 30）且数据明显非正态
- 有序数据（评分、排名）
- 存在无法移除的严重异常值
- 偏斜分布
```

**何时使用参数检验：**

```
- 大样本量（中心极限定理使检验统计量近似正态）
- 数据大致对称，无极端异常值
- 更大的统计功效（更擅长检测真实差异）
```

在机器学习实验中，你通常只有小量的 n（5 或 10 折交叉验证），因此非参数检验如 Wilcoxon 符号秩检验往往比 t 检验更合适。

### 中心极限定理：实际意义

中心极限定理（Central Limit Theorem, CLT）指出，随着 n 的增长，样本均值的分布趋近于正态分布，无论底层总体的分布如何。

```
如果 X_1, X_2, ..., X_n 独立同分布，均值为 mu，方差为 sigma^2：

    X_bar ~ Normal(mu, sigma^2 / n)    当 n -> 无穷大

大多数情况下 n >= 30 即可。
对于高度偏斜的分布，可能需要 n >= 100。
```

**这对机器学习的意义：**

```
1. 为聚合指标上的置信区间和 t 检验提供理论支撑
2. 解释了为什么对交叉验证折求平均能得到稳定的估计，
   即使单个折的变化很大
3. 小批量梯度下降之所以有效，是因为批次上的平均梯度
   近似于真实梯度（中心极限定理的实际应用）
4. 集成方法：对多个模型的预测取平均比任何单个模型
   的输出更稳定
```

**中心极限定理不能做的事：**

```
- 不会使你的数据变成正态分布。它使样本的均值趋近正态。
- 不适用于方差无穷大的重尾分布（如柯西分布）。
- 不适用于相关数据（未做校正的时间序列）。
```

### 机器学习论文中常见的统计错误

1. **在训练集上测试。** 保证过拟合。始终留出模型在训练过程中从未见过的数据。

2. **没有置信区间。** 仅报告一个准确率数字而不附带不确定性，使结果不可复现且无法验证。

3. **忽视多重比较。** 测试 50 种配置并报告最佳结果而不做校正，会夸大假阳性率。

4. **混淆统计显著性和实际显著性。** 对 0.01% 的准确率提升得到 p = 0.001 并没有实际意义。

5. **在不平衡数据上使用准确率。** 在 99% 为负类的数据集上获得 99% 的准确率意味着模型什么都没学到。应使用精确率、召回率、F1 或 AUC。

6. **挑选指标。** 只报告模型表现最好的那个指标。诚实的评估应报告所有相关指标。

7. **在训练/测试划分之间泄露信息。** 在划分之前做归一化，或使用未来数据来预测过去。

8. **小测试集且无方差估计。** 在 100 个样本上评估并声称 2% 的提升是噪声，不是信号。

9. **假设独立性但数据并非独立。** 来自同一患者的医学影像、来自同一文档的多个句子。组内的观测是相关的。

10. **p 值操纵（P-hacking）。** 尝试不同的检验、子集或排除标准，直到得到 p < 0.05。结果只是搜索的产物。

## 动手实现

你将实现以下内容：

1. **从零实现描述性统计**（均值、中位数、众数、标准差、百分位数、四分位距）
2. **相关性函数**（Pearson 和 Spearman，以及协方差矩阵）
3. **假设检验**（单样本 t 检验、双样本 t 检验、卡方检验）
4. **自助法置信区间**（适用于任何统计量，不需要假设）
5. **A/B 测试模拟器**（生成数据、检验、检查第一类和第二类错误）
6. **统计显著性 vs 实际显著性演示**（展示大 n 如何使所有差异都变"显著"）

全部从零实现，仅使用 `math` 和 `random`。不用 numpy，不用 scipy。

## 关键术语

| 术语 | 定义 |
|---|---|
| 均值（Mean） | 值的总和除以个数。对异常值敏感。 |
| 中位数（Median） | 排序数据的中间值。对异常值鲁棒。 |
| 标准差（Standard Deviation） | 方差的平方根。以原始单位衡量离散程度。 |
| 百分位数（Percentile） | 低于该值的数据所占的百分比。 |
| 四分位距（IQR） | Q3 减 Q1。中间 50% 数据的分布范围。 |
| Pearson 相关系数 | 衡量两个变量之间的线性关联。范围 [-1, 1]。 |
| Spearman 相关系数 | 使用秩来衡量单调关联。 |
| 协方差矩阵（Covariance Matrix） | 所有特征之间成对协方差的矩阵。 |
| 零假设（Null Hypothesis） | 无效果或无差异的默认假设。 |
| p 值（p-value） | 在零假设为真的前提下，观察到如此极端数据的概率。 |
| 置信区间（Confidence Interval） | 在给定置信水平下，参数的合理取值范围。 |
| t 检验（t-test） | 检验均值是否存在显著差异。使用 t 分布。 |
| 卡方检验（Chi-squared Test） | 检验观察频率是否与期望频率不同。 |
| 效应量（Effect Size） | 差异的大小，与样本量无关。Cohen's d 是常用指标。 |
| Bonferroni 校正 | 将显著性阈值除以检验次数，以控制假阳性。 |
| 自助法（Bootstrap） | 有放回地重采样以估计抽样分布。 |
| 第一类错误（Type I Error） | 假阳性。在 H0 为真时拒绝 H0。 |
| 第二类错误（Type II Error） | 假阴性。在 H0 为假时未能拒绝 H0。 |
| 统计功效（Statistical Power） | 正确拒绝假 H0 的概率。功效 = 1 减去第二类错误率。 |
| 中心极限定理（Central Limit Theorem） | 随着样本量增大，样本均值收敛到正态分布。 |
| 参数检验（Parametric Test） | 假设数据服从特定分布（通常是正态分布）。 |
| 非参数检验（Non-parametric Test） | 不做分布假设。基于秩或符号。 |
